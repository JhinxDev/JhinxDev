## Selected projects

- **[Omakase Plus](https://github.com/JhinxDev/omakase-plus)** is a self-hosted anime, movie, and TV discovery platform with a Web Hub, native Apple TV (tvOS) and iPhone (iOS) SwiftUI apps, GHCR Docker deployment, an account-scoped stdio MCP server and JSON CLI, automated TestFlight CI, and live Playwright latency benchmarks. [Documentation](https://omakase-plus.jhinx.dev/)
- **[Cadence](https://github.com/JhinxDev/cadence)** is a clean-room, MIT-licensed native iOS and Apple CarPlay music player with a self-hosted Python/FastAPI Discovery Companion for Navidrome and OpenSubsonic libraries, featuring vibe-aware Speed Dial and Quick Picks, personalized mixes, infinite radio, live search, synced lyrics, offline caching, and automated TestFlight CI.
- **[Sona (v0.7.2)](https://github.com/JhinxDev/Sona)** is a local Windows voice dictation app (C#/.NET, Parakeet and Whisper local inference) shipped as a self-contained installer with SHA-256 checksums, reviewable drafts, Discord mic mute, safe clipboard handling, and automated Windows CI tests.
- **[Vespera](https://github.com/JhinxDev/vespera)** is a self-hosted multi-platform publishing workbench (Node.js 24, SQLite, React 19, Tailwind CSS v4, Playwright isolated browser profiles, on-demand noVNC live browser, HMAC-SHA256 webhooks, and a stdio MCP server for AI agents).
- **[Omakase](https://github.com/JhinxDev/omakase)** is an LLM-powered anime recommendation CLI and FastAPI web app supporting local (Ollama, LM Studio, OpenWebUI) and cloud models. [Live demo](https://omakase.jhinx.dev/)
- **Agentic Workflows & Homelab Infrastructure** operate across Codex, Claude Code, and Antigravity with reusable skills, custom MCP servers, cost-capped multi-model evaluation, and a multi-node Proxmox, Linux, LXC, and Docker homelab with Cloudflare Tunnels, Prometheus monitoring, and automated backups.
